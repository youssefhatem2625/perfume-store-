# ✨ دار أثير — Luxury Oriental Perfumes Boutique

واجهة متجر إلكتروني فاخر لبراند عطور شرقية ونيش بطابع ملكي داكن وميزات تجارة إلكترونية متقدمة.

## 🌟 المميزات
- **سلة مشتريات جانبية تفاعلية (Interactive Slide-over Cart Drawer):** تحديث الكميات وحساب الإجمالي بدون إعادة تحميل الصفحة.
- **محرك كوبونات الخصم الفوري (Promo Code Engine):** خصم فوري عند إدخال الكود (جرّب: `ATHEER10`).
- **هرم النوتات العطرية التفاعلي (Interactive Scent Pyramid):** استكشاف قمة العطر وقلبه وقاعدته ومكوناته.
- **مبدل الحجم والسعر لحظياً:** اختيار عبوة 50 مل أو 100 مل وتحديث السعر على الفور.
- **متجاوب 100%:** تجربة تسوق مريحة على جميع الأجهزة وشاشات الموبايل.
